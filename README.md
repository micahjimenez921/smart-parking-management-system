# Smart Parking Management System

## Project Overview
The Smart Parking Management System is an Object-Oriented Programming (OOP) project designed to organize parking operations and manage parking slot assignments.

## Objectives
- Assign available parking slots to vehicles.
- Record vehicle entry and exit.
- Track parking duration.
- Calculate parking fees.
- Manage parking slot availability.

## Main Users
- Driver
- Parking Attendant
- System Administrator
